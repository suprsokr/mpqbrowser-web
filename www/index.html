MPQ Browser

Click a .blp texture to preview it, an .m2 model for an interactive 3D viewer with animations and the textures it binds, an .adt terrain tile to fly over it with its layer textures listed, a .dbc table to read it with its column names, or a .wav / .mp3 to listen.

How it reads the archives

Every format is the benilla client's own code, compiled to WebAssembly: benilla-mpq for the archives, benilla-blp for textures and benilla-formats for models and the character tables. A local server streams byte ranges, so no archive is loaded into browser memory. Select Folder works without that server when the browser has the File System Access API.
